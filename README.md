# Portfolio Gabriella D’Andretta

## File
- `index.html`: struttura e contenuti della pagina.
- `style.css`: palette, layout, componenti, responsive design e animazioni CSS.
- `script.js`: menu mobile, animazioni on-scroll, finestra showreel e anno automatico.

## Come provarlo
1. Estrai lo ZIP in una cartella.
2. Apri la cartella con Visual Studio Code.
3. Apri `index.html` nel browser. È consigliato usare l'estensione **Live Server** di VS Code.
4. Serve una connessione Internet per Google Fonts, Tailwind CDN e immagini Unsplash.

## Prima di pubblicare
- Sostituisci `INSERISCI-EMAIL@ESEMPIO.IT` con l'indirizzo reale.
- Verifica e aggiorna il profilo Instagram.
- Sostituisci le immagini di esempio con anteprime dei progetti reali.
- Collega il pulsante Showreel al video effettivo.
- Verifica i diritti e i permessi per tutte le immagini e i video utilizzati.

## Scelte tecniche
Il CSS puro contiene i componenti e gli stili riutilizzati (palette, navigazione, card, sezioni, footer). Tailwind è incluso via CDN solo per utility occasionali, come richiesto; in questa prima versione il layout è realizzato soprattutto con CSS dedicato perché richiede un controllo preciso del design.
